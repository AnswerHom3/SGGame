# 代号SG 战斗原型骨架

Game004 横版可玩骨架：移动、跳跃、轻击三连。命中窗口仍是占位。着地移动播 Run，停下播 Idle。轻击按目标时长播赵云 mainline 帧，脚在挥击中锁定。

## 操作

- **左下虚拟摇杆**：只认水平。死区 `0.15`。推满是 `MOVE_SPEED`（5 m/s），中间按比例，松开同一帧停下，没有惯性
- **A / D** 或 **← / →**：桌面调试，按满速。摇杆有输入时以摇杆为准
- 朝向跟着移动方向翻转。挥击过程中不转向
- **Space / W / ↑**：跳跃（着地，且不在轻击中，或正处于取消窗口）
- **J**：轻击。三连；取消窗口内再按进入下一击
- **Z**：开关物理调试线
- 屏幕右下 **跳跃**、**轻击** 与键盘相同。左下留给摇杆
- 镜头不跟角色。人被夹在画面边缘里，走不出去

同一帧既跳又按轻击时，取消窗口开着则跳跃优先。空中按下的轻击会保留 `INPUT_BUFFER_SEC`（0.12 秒），落地且仍在缓冲内才出招。挥击中、取消窗口还没开时的轻击记入 `LIGHT_INPUT_BUFFER`（0.10 秒），并至少留到取消窗口打开再接上，不会被丢掉。

招式收招结束后，连段再保留 `LIGHT_COMBO_RESET`（0.5 秒）。这段时间里再按就接下一段；超过才从 light1 重开。命中木桩时顿帧 `HIT_STOP`（0.10 秒，时间缩放）。伤害仍只计一次。

## 现在是真的

- 左右速度、跳跃初速、重力写在物理刚体上
- 轻击 1 → 2 → 3 的状态机，带命中窗口和取消窗口
- 挥击时锁朝向，前冲为 0，脚不滑动。判定盒挂在右手枪尖上，随朝向镜像
- 轻击主线按 0.40 / 0.46 / 0.62 秒取帧。1/2 收招只在没接上下一击时播；第三击正常收招回 Idle
- 右侧木桩只做受击计数（没有血、没有受击动作）。命中窗口与木桩重叠时记一次
- 轻击收招结束后 `LIGHT_COMBO_RESET`（0.5 秒）内再按，连段不中断
- 取消窗口前的轻击会缓冲到窗口打开
- 命中顿帧 `HIT_STOP`（0.10 秒）。计数和顿帧分开

## 占位，不要当成定稿

| 击 | 时长 | 命中窗口 | 取消窗口 | 取消后 | 前冲 | 判定盒（宽, 高, 枪尖前移） |
| --- | --- | --- | --- | --- | --- | --- |
| light1 | 0.40s | 0.10–0.20 | 0.34–0.40 | 立即接 light2 | 0（脚锁定） | 1.15, 0.38, 0.15 |
| light2 | 0.46s | 0.12–0.24 | 0.40–0.46 | 立即接 light3 | 0（脚锁定） | 1.25, 0.42, 0.20 |
| light3 | 0.62s | 0.16–0.30 | 0.52–0.62 | 本击结束后才重开 light1；跳跃仍可立刻取消 | 0（脚锁定） | 1.55, 0.55, 0.35 |

时间从每一击自己的起点算，区间左闭右开。取消窗口靠近每段末帧，起手连打不会提前切走。前冲分支还在，数值是 0：命中窗口内速度为 0 时脚不移动。画布缩放和视口边界变化也不会在 `vx == 0` 的挥击里改角色 X。

其它占位：移动 `5.0 m/s`，跳跃 `10.0 m/s`，重力 `20.0 m/s²`。连段清零 `LIGHT_COMBO_RESET` 0.5 秒（从收招结束算），轻击输入缓冲 `LIGHT_INPUT_BUFFER` 0.10 秒，顿帧 `HIT_STOP` 0.10 秒。全部常量在 `scripts/combat/tuning.lua`。

轻击 3 的取消窗口只接跳跃或“打完再开下一轮”，不会在收招中段把终结击切掉。

## 美术

- 地面和木桩仍是色块。赵云用 256 画布贴图：Idle、Run、轻击。图片没加载到时退回色块
- **着地移动播 Run**。`scripts/combat/tuning.lua` 的 `MOVE_CLIP` 是 `"run"`。停下播 Idle
- Run：`assets/characters/hero_zhaoyun/run/hero_zhaoyun_run_000.png` … `_007.png`，8 帧，**8 fps**（每帧 125 ms，循环 1.0 秒）。不要按 10 fps 播；10 fps 预览比源周期快 25%
- Run 画布注册 / root ≈ `(128, 248)`。绘制偏移是 `(0, 0)`。不要套用 Idle 的 `(−17, −1)`
- Idle 仍是 12 帧、**10 fps**。绘制偏移只属于 Idle：水平 `IDLE_DRAW_OFFSET_X_PX = -17`（128 − 145），竖直 `IDLE_DRAW_OFFSET_Y_PX = -1`。不要改 PNG
- 轻击 v1：`assets/characters/hero_zhaoyun/atk_light/` 共 86 张。mainline 按目标时长对帧（0.40 / 0.46 / 0.62 秒），不要按 10 fps。建议等间隔约 27.5 / 43.48 / 25.81 fps，实现是时间映射到帧号
- 正常连段：light1 → light2 → light3 → light3_recover → Idle。light1_recover（13 帧）、light2_recover（11 帧）只在这段没有接下一次时播。收招按源均值帧率（约 12.48 / 12.57 / 12.41 fps），不套攻击目标速度
- 轻击 root 是 `(128, 248)`，绘制偏移 `(0, 0)`，画布缩放 1。相对 Idle 约 80%，相对 Run 约 83%。脚登记在 root 上，体型差可能还在，不能说已经无缝对齐
- light3 是通过的下劈，不是旧横扫。下劈冲击帧上的紫白冲击图是源片内容
- light2 冲击帧 016 枪尖被裁，坐标是空，不能当成 `(0, 0)`。调试时可以用 017 的可见尖端代替，只用于调试标记
- 源 Run / 轻击帧面朝右、没有嘴、枪在右手

## 右手枪

赵云的枪锁在右手。面朝右时，握点在身体中心前方 `0.32 m`、高 `0.22 m`，枪尖在前方 `1.05 m`、高 `0.42 m`。判定盒中心在枪尖再往前一点，后沿仍在握点前面，不会打到背后。面朝左时整组偏移乘以朝向。

## 代码

- `scripts/combat/light_attack.lua`：三连窗口、输入缓冲、收招后的连段计时
- `scripts/combat/light_anim.lua`：主线按时长取帧，中断才播 1/2 收招
- `scripts/combat/hero_sheet.lua`：贴图缓存。缩放只影响绘制
- `scripts/combat/hit_stop.lua`：命中顿帧（时间缩放），不改伤害
- `scripts/combat/hero.lua`：移动、跳、朝向锁定、脚锁定
