# 序列帧自检标准

老板定稿。攻击动作人物会飘时，优先按本标准卡「脚底锚点」和「固定画布」，多数情况不用重画。

## 一、必须遵守的硬约定

1. 同一角色、同一套动作，所有帧用同一画布尺寸（宽高固定），不跨格、不贴边，四周留至少 8 到 16 像素透明边。
2. 地面角色语义锚点统一为脚底中心（两脚触地点的中点）；飞行或纯特效才用身体中心。禁止用「整图包围盒中心」当锚点。
3. 播放时只换图，角色节点的世界坐标和 pivot 不改。若图集做了 Trim，必须保留原画布宽高和裁切偏移，否则直接交未裁固定格。
4. 引擎侧：Unity 同角色统一 Pixels Per Unit，pivot 设底部居中或自定义脚点；Godot 同一动画各帧同高，并用同一套 centered 和 offset。（本项目为 TapMaker / Lua，原则相同：只换图，脚锚与世界坐标不随帧乱跳。）

## 二、出图前检查

- 画布宽高、行列、脚底基线写进任务单；AI 提示词里写明「双脚基准位置与角色中心每帧一致」。
- 攻击帧允许手臂、武器、披风伸出，但脚底锚点像素坐标不变；动作位移由程序位移完成，不靠画面里角色整体平移来表现冲刺。
- 阴影、刀光、尘土单独图层或单独序列，不要画进角色主层，避免「最低像素」被阴影骗成假脚点。

## 三、导出后自检（约 5 分钟，不过不交）

1. 锁死角色世界坐标和相机，把该动作全部帧叠在同一左上角。
2. 画一条脚底水平线、一条身体中心竖线。循环播放时，脚点在水平线上左右晃动不超过 1 像素；竖直方向不得上下跳。
3. 末帧接回首帧时不得跳一下。
4. 攻击冲击帧与待机帧叠看：躯干可扭、可前倾，但脚底锚点仍落在同一点。
5. 若某帧漂了：按「公共锚点 − 局部锚点」做整数像素平移对齐，写进交付表；不要靠引擎里每帧改 offset 凑。

## 四、交付物清单

- 固定格 PNG 序列或图集
- 一页对照表：动作名、帧号、画布尺寸、脚点坐标（相对左下或约定原点）、是否 Trim、Trim 偏移、对应特效名
- 一张叠帧自检截图（脚底线可见）

## 五、判定标准（过 / 不过）

- **过**：叠帧脚点抖动 ≤1px，末首衔接无跳，引擎内攻击全程人物不「飘」
- **不过**：按包围盒居中、每帧画布尺寸不同、Trim 无元数据、用画面位移代替程序位移
