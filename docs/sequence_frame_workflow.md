# 代号SG · 序列帧工作流规范（制作人 · 2026-11-07）

老板验收通过后沉淀。本规范管**谁做什么、按什么顺序、卡什么门**：从任务单到关键姿、视频、导帧，再进游戏。像素细则见 [sequence_self_check_standard.md](./sequence_self_check_standard.md)，美术勾选见 [sequence_export_checklist_art.md](./sequence_export_checklist_art.md)。

---

## 0. 一句话

**需求进任务单；美术锁身份、关键姿点头后再出视频，真抽帧交钉脚固定格；测试叠帧签人物像素；程序只换约定动作并同步脚点配置；攻击位移永远走程序，不靠画面平移。**

## 1. 角色分工

| 角色 | 负责 | 不负责 |
|---|---|---|
| **美术** | 锁身份与关键姿；I2V 原片入库 `review/`；真抽帧出固定格 PNG；钉脚；统一 content_h；写 FOOT_REGISTRATION / README / QC | 改引擎 offset 救脚；用 renderScale 补尺度 |
| **程序** | 接入交付包；同步 `frames` / `plantedSole` / canvas / pivot；攻击位移与硬门禁1 | 擅自裁帧；只换图不改脚点族 |
| **测试** | 叠帧签脚点与 content_h；硬门禁1；青线；出码后眼测 | 感觉扫码当正式 PASS |
| **制作人** | 出任务单；定基准（帧数 / content_h / 脚点族）；卡交接；推进门禁；沉淀规范 | 替职种改资产或写业务代码 |
| **老板** | 点头关键姿；可先过视频节奏；眼测定调；签发硬门禁；文档「合」 | — |

策划案另线。序列帧只认任务单：任务单没写的帧数、尺度、切口，不从策划案临时加。

## 3. 制作全链路（必须按序，不可跳）

整链：**需求 → 单帧/关键帧 → 视频 → 导序列帧 → 进游戏**。A–D 是上游制作段；E 接原流水线后半（交付后门禁）。未过的步不往下走。

| 段 | 对应原流水线 |
|---|---|
| A 出需求 | 原 ① 任务单 |
| B 身份锁 + 单帧/关键帧 | 原流水线未单列，补在出包之前 |
| C 出视频 | 同上；节奏不过不抽帧 |
| D 导序列帧 + 自检 | 原 ②③ |
| E 应用进游戏 | 原 ④–⑨ |

**铁律不在本链放宽（细则 §5、§6）：** 量人物不量画布；禁止程序补尺；缩帧要批；换 Idle = 换脚点族。

### A. 出需求（制作人）

任务单写死，下游只认这一张：

1. 动作名
2. 目标帧数
3. 画布
4. content_h 基准（现行数字见 §2；赵云轻击静息 ≈190）
5. 是否动 Idle_000
6. 时长 / 节奏
7. 连招切口

策划案另线。本段只认任务单。任务单没写的，美术不猜、程序不补。

### B. 身份锁 + 单帧 / 关键帧（美术）

1. **Master / identity 锁定**：品红底、朝右、枪尖不裁。身份未锁，不出姿、不出视频。
2. 出单帧或关键姿：Idle 静息、攻击命中姿等。**老板先点头姿，再进动。**
3. 关键帧只定姿与枪位衔接（连招切口以任务单为准），不是全套序列。全套序列只在 D 从原片抽出。

### C. 出视频（美术）

1. 以已点头的单帧 / 关键姿做 I2V：固定机位、品红底、脚不滑。
2. 原片入库 `review/`，同处写 `generation_record`（源单帧或关键姿、原片路径；供 D 标源帧区间）。
3. 老板可先过视频节奏。**节奏不过，不抽帧。** 视频里脚不滑只约束原片；进游戏后的攻击位移仍走程序，不靠画面平移。

### D. 导序列帧（美术）

1. 从原片**真抽帧**。README 标明源片与源帧区间。禁止无说明插值 / 混帧。
2. 品红抠底 → 固定画布 PNG（透明底进包，见 §4）→ 统一缩到基准 content_h（赵云轻击静息 ≈190，见 §2）。
3. 钉脚：sole span ≤1；Idle 的 content bottom = 0。攻击 recover 尾帧钉**现行** Idle_000（见 §6）。
4. 交包：png + FOOT_REGISTRATION + QC + README + zip（最低集见 §4）。自检按标准 §三 / §六，不过不交。

### E. 应用进游戏

与原流水线后半对齐，顺序不可跳：

```
④ 测试叠帧签 PASS
   → n 帧数、content_h、sole span、content bottom；对照现行 Idle_000
⑤ 程序接入（只换约定范围）
   → 同步 frames 列表 + plantedSole + canvas；renderScale = 1；其它动作默认不动
⑥ 程序硬门禁1 自测 → 出一版预览码
⑦ 测试青线 + 硬门禁1 + recover→Idle 接缝
⑧ 制作人 @老板 眼测（一码一次；测试未点头不出）
⑨ 老板点头 → 归档包路径与码号；失败则回 D 或 ⑤，禁止叠补丁糊弄
```

**原则：** 程序不接未叠帧 PASS 的包；测试不以「感觉可以」代正式 PASS；一版问题收敛后再出下一码。上游未过（姿未点头、视频节奏未过、源帧区间未写明）不得进入 E。

## 4. 交付包最低集

每个动作包目录必须含：

1. `pngNNN/` 或约定画布目录：全帧 PNG，命名 `hero_xxx_动作_###.png`
2. `FOOT_REGISTRATION.md`：Idle_000（或本夹 frame0）join 参考；scale；gates
3. `foot_registration.csv` / `.json`（有则更好）
4. `qc/`：叠帧图 + `validation.json`（`all_pass`）
5. `README.md`：源包、源帧区间、帧数、content_h、已知限制
6. `*_game_ready.zip`

缺脚底表 / 缺帧数说明 / 缺源帧区间 / 只报画布不报 content_h → **拒收**。

---

## 5. 尺度与帧数铁律

1. **量人物，不量画布。** `content_h` = 不透明包围盒鞋底→头顶；交付表必写 min/avg/max。
2. **夹间对齐基准动作**（赵云 = 轻击静息 ≈190）。Idle/Run/Atk frame0 脚底叠看，内容身高不可跳档。
3. **禁止**用程序 `renderScale` 或每帧 `drawOffset` 补美术尺度。
4. **帧数是产品规格。** 缩帧（如 12→5）必须制作人批准并写进 README「为何短循环」；磁盘上有多帧但 Config 未挂 = 视为缩帧，同样要说明。
5. 同源试验包与正式包尺度不一致时（例：`idle_direct_12` vs 旧 game-pkg 5 帧），**禁止混接**；要恢复帧数必须「源帧 → 缩到基准 content_h → 钉脚」整链重出。

---

## 6. 脚点族与 recover 接缝

1. 每个正式 Idle 包有唯一 **Idle_000 join sole**。换 Idle = 换脚点族。
2. 程序接入 Idle 时必须同时更新：
   - `IdleConfig.frames`（全帧）
   - `plantedSoleX/Y`（新 Idle_000）
   - 相关注释 / FOOT 引用
3. **禁止**只换 PNG、沿用旧 `plantedSole`。
4. 攻击 recover 尾帧必须钉向**现行** Idle_000。脚点族变更后：
   - 测试先验 recover→Idle hop
   - ≥2px 或老板喊「咔一下」→ 美术按新 Idle_000 重钉 recover 尾帧，再出码
5. 剪影接缝（XOR 观感）与脚点 hop 分开记；脚点 PASS 仍可因剪影单开重导，须制作人排期。

## 7. 程序接入检查单

- [ ] 只替换任务指定的动作目录
- [ ] `frames` 与交付 PNG 张数、编号一致（含前导零）
- [ ] `plantedSole` / pivot / canvasSize 与 `FOOT_REGISTRATION` 一致
- [ ] `renderScale = 1`；Idle/Run `drawOffset = 0`（除非制作人改基准）
- [ ] 攻击位移：无画面整体平移；硬门禁1 自测 PASS
- [ ] 出码号写入群；旧码标废
- [ ] 不接测试未叠帧 PASS 的包

---

## 8. 测试检查单（摘要）

- [ ] 准入：png + 脚底表 + QC + README
- [ ] 叠帧：帧数 n、content_h、sole span≤1、content bottom span=0（Idle）
- [ ] 夹间：与基准动作 content_h / 脚底线
- [ ] 硬门禁1：攻击无位移
- [ ] 起手 / 切段 / 回 Idle hop <2px
- [ ] 正式 PASS 才叫程序出码给老板；感觉扫码 ≠ PASS

细则可另维护轻击复验清单。

## 9. 群协作约定

1. 美术交包：贴**绝对路径** + 帧数 + content_h + join sole + `@程序` `@测试`。
2. 测试只回 **PASS/FAIL + 关键数**；FAIL 写回哪一环。
3. 程序出码：贴码号 + 改了什么（frames / plantedSole / 其它）+ 废码声明。
4. 制作人：同时只推一条主线；老板未点头不开下一视觉项。
5. 文档进仓库要老板说「合」；未合前以 `/workspace/sg-art/docs/` 本文件为准。
